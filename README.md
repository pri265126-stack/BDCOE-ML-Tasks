# BDCOE ML Tasks 🚀

This repository contains all Machine Learning tasks completed for the BDCOE ML Society.

## Projects

### 📊 Task 1 — Spotify EDA Project

* Exploratory Data Analysis on Spotify songs dataset.
* Libraries used: Pandas, Matplotlib, Seaborn.

### 📩 Task 2 — Spam Classifier Project

* SMS Spam vs Ham classification using Machine Learning.
* Techniques used:

  * Data Cleaning
  * TF-IDF Vectorization
  * Multinomial Naive Bayes
  * Model Evaluation (Accuracy, Precision, Recall, F1-Score, Confusion Matrix)
